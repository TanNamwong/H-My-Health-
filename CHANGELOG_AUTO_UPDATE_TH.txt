H My Health V11 — รองรับการอัปเดต PWA โดยไม่ต้องลบและติดตั้งใหม่

สิ่งที่เพิ่ม:
- ตรวจหาเวอร์ชันใหม่เมื่อเปิดแอป กลับมาที่แอป และตรวจซ้ำทุก 6 ชั่วโมงเมื่อออนไลน์
- แจ้งเตือนกลางจอเมื่อมีเวอร์ชันใหม่ พร้อมปุ่มอัปเดตตอนนี้/ไว้ภายหลัง
- ดาวน์โหลดไฟล์แอปเวอร์ชันใหม่ลงแคชก่อน แล้วจึงสลับเวอร์ชันเมื่อผู้ใช้กดยืนยัน
- ข้อมูลสุขภาพใน localStorage ไม่ถูกลบระหว่างอัปเดต
- ยังคงใช้งานไฟล์ที่แคชไว้ได้เมื่อออฟไลน์

ข้อจำกัดแพลตฟอร์ม:
- ใช้ได้กับเว็บแอปที่ติดตั้งเป็น PWA บน Android และ iOS เมื่อเปิดผ่าน HTTPS และเบราว์เซอร์รองรับ Service Worker
- การตรวจพบ/ดาวน์โหลดเวอร์ชันใหม่ต้องมีอินเทอร์เน็ต โดยปกติจะตรวจเมื่อเปิดหรือกลับเข้าแอป ไม่สามารถบังคับอัปเดตขณะปิดแอปได้
- นี่คือการอัปเดตส่วนเว็บของ PWA ไม่ใช่การอัปเดต APK หรือแอป native ผ่าน App Store/Play Store
- การเปลี่ยนแปลงโค้ดจะมีผลต่อผู้ใช้เมื่อผู้ดูแลเผยแพร่ไฟล์เวอร์ชันใหม่ไปยังโฮสต์ HTTPS เช่น GitHub Pages

การตรวจสอบที่ทำ:
- node --check สำหรับ JavaScript ทั้งสองบล็อกใน index.html: ผ่าน
- node --check service-worker.js: ผ่าน
- ยังไม่ได้ทดสอบบนอุปกรณ์ iOS/Android จริง และยังไม่ได้เผยแพร่ขึ้น GitHub Pages
