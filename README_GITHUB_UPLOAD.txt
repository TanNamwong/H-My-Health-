H MY HEALTH V11 — OFFLINE / LOCAL ONLY

ข้อกำหนดสำคัญ
- ไม่มีบัญชีผู้ใช้ ไม่มีระบบออนไลน์ ไม่มี Cloud และไม่มีการซิงก์ข้อมูล
- ข้อมูลสุขภาพเก็บใน localStorage ของเบราว์เซอร์บนอุปกรณ์นี้
- ต้องเปิดแอปครั้งแรกขณะมีอินเทอร์เน็ตเพื่อให้ Service Worker ดาวน์โหลดไฟล์และแคชแอปก่อน
- หลังจากแคชครบแล้วจึงเปิดใช้งานแบบออฟไลน์ได้ (การแจ้งเตือนเบื้องหลังขึ้นกับเบราว์เซอร์/Android)

ฟังก์ชันใน V11
1. บันทึกค่าความดัน ชีพจร SpO2 น้ำตาล และอุณหภูมิ
2. ประวัติสุขภาพและรายงาน PDF
3. กราฟแนวโน้มย้อนหลัง 7 / 30 / 90 วัน
4. เปรียบเทียบจำนวนการบันทึกและค่าเฉลี่ยกับเดือนก่อน
5. รายการยาและการแจ้งเตือนเมื่อเปิดแอป
6. ปุ่ม “กินยาแล้ว” พร้อมประวัติวันและเวลาที่กดยืนยัน
7. นัดตรวจพร้อมการเตือนล่วงหน้า
8. ข้อมูลฉุกเฉิน: หมู่เลือด ประวัติแพ้ยา ผู้ติดต่อฉุกเฉิน
9. ตั้ง PIN, สำรองและกู้คืนไฟล์ข้อมูล
10. คู่มือพร้อมภาพประกอบแยก 1 ภาพต่อหัวข้อ

วิธีอัปเดต GitHub Pages
1) แตก ZIP
2) อัปโหลดไฟล์ทั้งหมดใน ZIP ไปยังโฟลเดอร์เดียวกับ index.html เดิม (root ของ Pages)
3) Commit changes และรอ GitHub Pages เผยแพร่
4) เปิดแอปขณะออนไลน์หนึ่งครั้ง รอให้โหลดครบ จากนั้นทดสอบเปิดโหมดเครื่องบิน
5) หากยังเห็นหน้ารุ่นเก่า ให้ปิดแท็บแอปแล้วเปิดใหม่ หรือเคลียร์ข้อมูลเว็บไซต์ (สำรองข้อมูล JSON ก่อนเสมอ)

ไฟล์หลักที่ต้องอยู่ระดับเดียวกัน
- index.html, service-worker.js, manifest.webmanifest, .nojekyll
- icon-192.png, icon-512.png
- guide-*.svg ทุกไฟล์

ข้อควรทราบ
- ข้อมูลไม่ได้ย้ายข้ามโทรศัพท์อัตโนมัติ ต้องใช้สำรองข้อมูลและกู้คืนด้วยไฟล์ JSON
- การล้างข้อมูลเว็บไซต์/ถอนการติดตั้งเบราว์เซอร์อาจทำให้ข้อมูลสูญหาย
- การแจ้งเตือนผ่านเว็บไม่รับประกันเมื่อปิดแอปหรือระบบหยุดทำงาน
- การแสดงกราฟและการแจ้งเตือนเป็นเครื่องมือช่วยติดตาม ไม่ใช่การวินิจฉัยโรค
